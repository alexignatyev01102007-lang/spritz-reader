## 🚀 Что это такое?

Spritz Reader — это прогрессивное веб-приложение (PWA) для скорочтения текстов по технологии **Spritz**, основанной на методах **RSVP** (Rapid Serial Visual Presentation) и **ORP** (Optimal Recognition Point).

Приложение показывает текст слово за словом с высокой скоростью, фиксируя точку оптимального распознавания (ORP) на одном месте экрана. Это устраняет необходимость движения глаз и позволяет читать со скоростью **300–1000 слов в минуту** без потери понимания.

## 📱 Как использовать

### На компьютере:
1. Откройте [Spritz Reader](https://alexignatyev01102007-lang.github.io/spritz-reader/) в браузере
2. Нажмите **"Выбрать файл"** и выберите книгу
3. Настройте скорость, размер шрифта и шрифт под себя
4. Читайте!

### Установка на телефон (Android):
1. Откройте сайт в **Chrome**
2. Нажмите **⋮** (три точки) → **"Установить приложение"** или **"Добавить на главный экран"**
3. Приложение появится на рабочем столе

### Установка на iPhone (iOS):
1. Откройте сайт в **Safari**
2. Нажмите **"Поделиться"** → **"На экран Домой"**
3. Подтвердите установку

## 🎯 Как работает технология Spritz?

### RSVP (Rapid Serial Visual Presentation)
Текст показывается **по одному слову** в центре экрана с заданной скоростью. Это устраняет необходимость двигать глазами по строке.

### ORP (Optimal Recognition Point)
В каждом слове выделяется **красным цветом** точка оптимального распознавания — позиция, на которой глаз естественно фокусируется при чтении. Эта точка находится немного левее центра слова и зависит от его длины:

- Короткие слова (1–5 букв): центр слова
- Средние слова (6–9 букв): немного левее центра
- Длинные слова (10+ букв): ещё левее

Фиксация ORP на одном месте экрана позволяет мозгу мгновенно распознавать слова без дополнительных движений глаз.
